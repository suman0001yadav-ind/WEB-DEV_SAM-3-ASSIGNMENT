# Smart Utility Toolkit

Web Dev III Assignment 1

## Features
- CLI Calculator
- Custom Module (isEven)
- HTTP Server
- File Manager
- Random Dice Generator

## Run Commands

```bash
node calculator.js add 10 5
node app.js
node server.js
node fileManager.js
node dice.js
```
